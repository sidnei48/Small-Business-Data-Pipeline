Sobre o projeto

Transformando dados brutos em informação útil

Este projeto foi criado para transformar informações espalhadas em uma planilha em dados mais organizados, fáceis de analisar e úteis para o dia a dia de uma empresa.

No exemplo utilizado, os dados de uma escola de idiomas são organizados para facilitar a visualização de informações sobre alunos, professores, turmas e matrículas.

Como funciona

Do dado bruto até a visualização

1. Planilha

Os dados começam em uma planilha com informações da escola.

2. Tratamento

As informações são organizadas, corrigidas e preparadas para análise.

3. Banco de dados

Os dados tratados são armazenados de forma estruturada e segura.

4. Dashboard

As informações ficam disponíveis em gráficos e indicadores interativos.
