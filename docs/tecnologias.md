# Tecnologias Utilizadas

O projeto utiliza diferentes tecnologias para realizar as etapas de extração, transformação, armazenamento, análise e visualização dos dados.

## Python

Utilizado no desenvolvimento do pipeline ETL e na organização do fluxo principal do projeto.

## Pandas

Utilizado para leitura, limpeza, transformação, padronização e validação dos dados da planilha.

## PostgreSQL

Utilizado como banco de dados relacional para armazenar os dados tratados pelo pipeline.

## Psycopg

Utilizado para realizar a conexão entre o Python e o PostgreSQL, permitindo consultas, inserções e atualizações no banco.

## SQL

Utilizado para criação das tabelas, consultas, validações e análise dos dados armazenados.

## Power BI

Utilizado para criação do dashboard e visualização dos indicadores do projeto.

## Git

Utilizado para controle de versão do projeto.

## GitHub

Utilizado para armazenar o código-fonte, documentação e histórico de desenvolvimento.

## Visual Studio Code

Utilizado como ambiente de desenvolvimento para edição dos arquivos Python, SQL e Markdown.

## Python-dotenv

Utilizado para carregar as variáveis de ambiente definidas no arquivo `.env`, mantendo as credenciais do banco separadas do código-fonte.

## OpenPyXL

Utilizado pelo Pandas para leitura dos arquivos Excel utilizados como fonte de dados.
